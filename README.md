# 🏥 MedRemind (นัดหมอ-เตือนใจ)

โปรแกรมจัดการและแจ้งเตือนนัดหมายแพทย์ & ดูแลสุขภาพครอบครัวแบบ **Web App (Mobile-First / PWA)** 
พร้อมระบบแจ้งเตือน 2 ช่องทาง: **Discord Webhook** + **Google Calendar / ปฏิทินมือถือ (iOS/Android)** โดยใช้งาน **ฟรี 100%**

---

## ✨ ฟีเจอร์เด่น (Key Features)

1. **📱 Web App Dashboard สไตล์มือถือ (Mobile-First & PWA):**
   - หน้าตาการใช้งานทันสมัย ใช้งานผ่านมือถือได้อย่างสะดวก มีปุ่มลอย `+` กดเพิ่มนัดด้วยนิ้วโป้งง่ายๆ
   - ติดตั้งลงหน้าจอโฮมของมือถือ (iOS / Android) ได้เหมือนแอปจริงแบบไม่ต้องโหลดผ่าน App Store
   - มุมมองปฏิทินรายเดือน (Calendar View) และการ์ดรายการนัด (Timeline Cards)

2. **🔔 ระบบแจ้งเตือน 2 ช่องทาง (ฟรี 100%):**
   - **Discord Webhook:** ส่งข้อความแจ้งเตือน Rich Embed สวยงาม แยกสีตามคนในบ้าน แสดงข้อมูลนัดหมาย แผนก โรงพยาบาล และข้อปฏิบัติก่อนพบแพทย์
   - **Google Calendar (1-Click Sync):** กดปุ่มเดียวเปิดแอป Google Calendar พร้อมกรอกข้อมูล สถานที่ และตั้งเวลาแจ้งเตือนให้อัตโนมัติ
   - **ปฏิทินมือถือ iOS/Android (.ics):** ดาวน์โหลดไฟล์ `.ics` พร้อมระบบตั้งปลุก Alarm ในตัว (เตือนล่วงหน้า 7 วัน, 1 วัน, 2 ชม.)

3. **⏰ แจ้งเตือนหลายช่วงเวลาอัตโนมัติ (Multi-Stage Reminder):**
   - **ล่วงหน้า 7 วัน:** วางแผนเคลียร์คิวงาน / ลางาน
   - **ล่วงหน้า 3 วัน:** เตือนย้ำความจำ
   - **ล่วงหน้า 1 วัน (พรุ่งนี้):** เตือนข้อปฏิบัติ ข้อห้าม งดน้ำงดอาหาร
   - **เช้าวันนัด (07:00 น.):** สรุปข้อมูลสถานที่ แผนก และรูปใบนัด

4. **⚠️ ระบบบันทึกสิ่งที่ต้องเตรียมตัว & Checklist:**
   - บันทึกข้อห้าม/สิ่งที่ต้องเตรียม เช่น *งดน้ำ-อาหาร 8 ชม.*, *นำยาประจำตัวมาด้วย*, *เจาะเลือดก่อน 1 ชม.*, *พกแว่นสายตา*
   - มีปุ่มลัดเลือกข้อปฏิบัติได้ทันทีโดยไม่ต้องพิมพ์เอง

5. **📸 ระบบแนบรูปถ่ายใบนัดแพทย์ / ใบสั่งยา:**
   - ถ่ายรูปหรืออัปโหลดใบนัด/ใบสั่งยา/ผลตรวจแล็บเก็บไว้ดูย้อนหลัง
   - กดดูรูปขยายใหญ่เต็มหน้าจอบนมือถือได้ตลอดเวลา

6. **👨‍👩‍👧‍👦 จัดการนัดหมายแยกรายบุคคลในครอบครัว (Multi-Profile):**
   - บันทึกแยกของตัวเรา, คุณพ่อ, คุณแม่, ลูก ฯลฯ
   - มีไอคอน Emoji และแถบสีประจำตัวแยกชัดเจน กรองดูเฉพาะคนได้

## 🚀 วิธีเริ่มใช้งานบนเครื่องของคุณ (How to Run)

### วิธีที่ 1: ดับเบิลคลิกเปิดใช้งานทันที (แนะนำ)
1. เข้าไปที่โฟลเดอร์:
   ```
   C:\Users\winner\.gemini\antigravity\scratch\doctor-appointment-reminder
   ```
2. ดับเบิลคลิกที่ไฟล์ **`start.bat`**
3. โปรแกรมจะรันเซิร์ฟเวอร์และเปิดเบราว์เซอร์เข้าสู่ `http://localhost:3000` อัตโนมัติ

---

## ⚙️ วิธีตั้งค่าการแจ้งเตือนเข้า Discord (ฟรี)

1. เปิดแอป **Discord** บนคอมพิวเตอร์หรือมือถือ
2. ไปที่ Server และห้องแชทที่ต้องการรับแจ้งเตือน (หรือสร้าง Server ส่วนตัวสำหรับครอบครัว)
3. กด **ตั้งค่าห้อง (Edit Channel)** > เมนู **Integrations** > **Webhooks** > **New Webhook**
4. ตั้งชื่อ Webhook เช่น `นัดหมอ-เตือนใจ` แล้วกด **Copy Webhook URL**
5. เปิดหน้าเว็บ MedRemind > กดไอคอน **⚙️ (ตั้งค่า)** ที่มุมขวาบน > วาง Webhook URL ลงในช่อง > กด **🧪 ทดสอบส่งข้อความ**
6. กด **บันทึกการตั้งค่า** ระบบจะเริ่มส่งแจ้งเตือนอัตโนมัติตามกำหนดการทันที

---

## 📲 วิธีติดตั้งเป็นแอปลงบนมือถือ (PWA)

### สำหรับ iPhone / iPad (iOS Safari):
1. เปิดหน้าเว็บ `http://[IP-ของเครื่อง]:3000` บน Safari
2. กดปุ่ม **แชร์ (Share)** ด้านล่าง
3. เลือกเมนู **"เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen)**
4. ไอคอน MedRemind จะปรากฏบนหน้าจอเหมือนแอปทั่วไป เปิดใช้งานแบบเต็มจอได้ทันที

### สำหรับโทรศัพท์ Android (Google Chrome):
1. เปิดหน้าเว็บบน Chrome
2. กดปุ่ม **เมนู 3 จุด (⋮)** ที่มุมขวาบน
3. เลือก **"ติดตั้งแอป" (Install App)** หรือ **"เพิ่มลงในหน้าจอหลัก"**

## 🛠️ สถาปัตยกรรมเชิงเทคนิค (Technical Stack)

- **Backend Runtime:** Node.js v24 (Zero external dependencies)
- **Database:** SQLite ในตัว (`node:sqlite`) เก็บข้อมูลที่ `data/appointments.db`
- **File Storage:** Local uploads (`uploads/`)
- **Frontend:** Modern Mobile-First Responsive Web (Tailwind CSS, Vanilla ES6, PWA Service Worker)
- **Notifications:** Discord Webhook API (Rich Embeds) + RFC 5545 iCalendar + Google Calendar URL Generator
- **Scheduler:** Built-in Background Cron Daemon (Checking every 60 seconds)
